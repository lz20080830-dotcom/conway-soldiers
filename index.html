为什么无穷多颗棋子也跳不过第 4 格红线？

John Horton Conway (1961) · 黄金比例势能不变量证明

1. 给棋盘赋黄金比例权重

令 φ = (√5 − 1)/2 ≈ 0.618034（满足 φ² + φ = 1）。选定第 5 行任意目标格 T，给距 T 曼哈顿距离为 d 的格子赋权 φᵈ，则 T 自身权重为 φ⁰ = 1。

2. 任何合法跳跃都不会增加总势能 (ΔΣ ≤ 0)

  • 向目标 T 跳：φⁿ⁻² − φⁿ⁻¹ − φⁿ = φⁿ⁻²(1 − φ − φ²) = 0（守恒）
  • 等距横向跳：φⁿ − φⁿ⁻¹ − φⁿ = −φⁿ⁻¹ < 0（减少）
  • 远离目标跳：φⁿ⁺² − φⁿ⁺¹ − φⁿ = −2φⁿ⁺¹ < 0（大减）

3. 无穷下半平面的总势能上限恰好 = 1

把起跑线下方 (y ≤ 0) 所有无穷多个格子全部铺满棋子，总势能收敛为：

S₅ = [ φ⁵ / (1 − φ) ] × [ 1 + 2φ / (1 − φ) ] = 1

任何有限颗棋子的总势能严格 < 1；即便摆满无穷颗棋子，有限步后场上仍余无穷颗棋子（贡献 ε > 0），若有一颗抵达 T 则总势能需为 1 + ε > 1，与 ΔΣ ≤ 0 矛盾！

延伸：第 1～4 格最少分别需 2、4、8、20 颗棋子（可在左上角切换关卡观看演示）。Simon Tatham 与 Gareth Taylor 证明若允许“无穷多步”超任务可恰好抵达第 5 格；若允许斜跳，极限则变为第 8 格。
