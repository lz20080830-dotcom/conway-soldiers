# 完整验证版 · 四格红线验证

单页棋盘，用来动手验证 Conway's Soldiers（康威的士兵）。

棋子只能从起跑线下方（`y ≤ 0`）出发，并且只能沿上下左右跳过紧邻的一颗棋子，落在正后方的空格上。约翰·康威在 1961 年用黄金比例势能证明：无论在下方摆多少颗有限的棋子，有限步之内都到不了第 5 行。第 4 行是能摸到的最高边界。

本页把这件事做成可以摆、可以跳、可以看势能变化的验证器。第 1～4 格给出已知的最少棋子数解法（2、4、8、20 子），第 5 格则是真正铺满的无限下半平面，总势能恰好为 1，用来对照「为什么还是过不去」。

两个页面都是单个 HTML 文件，不依赖构建步骤、外部字体或远程脚本，断网也能打开。

## 如何打开

**本地：** 用浏览器直接打开 `index.html`（完整版）或 `v2.html`（极简版）。双击即可，不需要安装依赖。

**GitHub Pages：** 仓库 Settings → Pages → Build and deployment 选 Branch，分支选 `main`，目录选 `/ (root)`，保存。生效后地址形如：

`https://<用户名>.github.io/conway-soldiers/`

手机浏览器可以直接访问同一地址。极简版地址是同一站点下的 `v2.html`。建议竖屏先看完整红线，横屏时界面会收成一行。

## 完整验证版操作

### 触控 / 鼠标

| 操作 | 结果 |
| --- | --- |
| 点一颗棋子，再点绿色圆圈 | 跳过去 |
| 把棋子拖到绿色圆圈后松开 | 同样是跳 |
| 拖空白处 | 平移棋盘 |
| 双指捏合，或滚轮 | 缩放 |
| 底部 − / 居中 / + | 缩小、把起跑线和红线放进可视区域、放大 |
| 点第 5 行的格子 | 切换势能目标格 T |
| 底部「布阵」 | 在 `y ≤ 0` 点击或涂抹，添加 / 去掉棋子 |
| 左上角关卡名 | 切换第 1～4 格、第 5 格红线，或自由沙盒 |
| 顶部 Σ 条，或曲线图标 | 打开势能与每步 ΔΣ 日志 |
| 网格图标 | 无限下半平面、有限军阵、清空 |
| 眼睛图标 | 开关格子上的 φ 权重 |
| 书本图标 | 康威证明 |
| 喇叭图标 | 开关音效 |

第 5 格默认是无限棋盘。底部主按钮可在「无限棋盘」和「615 子有限阵」之间切换，用来对比总势能。第 1～4 格的主按钮会自动走出该关解法。

### 键盘

| 按键 | 结果 |
| --- | --- |
| 方向键 或 W A S D | 已选中棋子时，向该方向跳两格；没选中时平移视角 |
| + / − | 缩放 |
| Z | 撤销上一步跳跃 |
| R | 重置本关 |
| 0 或 Home | 居中并适配屏幕 |
| Esc | 关闭证明或弹出面板；都关掉时取消选中 |

证明窗口打开时，除 Esc 外的快捷键不会改动棋盘。

## 极简无限挑战操作

`v2.html` 一打开就是铺满的无限下半平面，没有关卡和布阵模式。

| 操作 | 结果 |
| --- | --- |
| 点棋子，再点绿色圆圈，或把棋子拖到绿圈 | 跳跃 |
| 拖空白处 | 平移 |
| 双指、滚轮，或底部 − / + | 缩放 |
| 居中 | 把起跑线和红线放进可视区域 |
| 点第 5 行 | 切换目标格 T |
| 撤销 / Z | 撤销上一步 |
| 重开 / R | 回到铺满的无限棋盘 |
| 极限残局 | 载入「差 (2,−1) 一子、再四连跳」的残局，坑里有随机孤岛 |
| φ 权重 | 开关格子上的 φᵈ |
| 喇叭 | 开关音效 |
| 方向键或 W A S D | 已选中棋子时跳跃；没选中时平移 |
| 完整版 | 回到 `index.html` |

顶部「逼近」是已经越过起跑线（`y ≥ 1`）的棋子，相对目标 T 的势能之和。越高越接近红线，但有限步到不了 100%。本局最高行和最高逼近会记在这台浏览器里（`localStorage`），极限残局不写入纪录。

## 规则摘要

- 黄金比例取 `φ = (√5 − 1) / 2 ≈ 0.618`，满足 `φ² + φ = 1`。
- 选定第 5 行目标格 T 后，曼哈顿距离为 d 的格子权重是 `φᵈ`。
- 任何合法跳跃的势能变化 `ΔΣ ≤ 0`：朝目标跳守恒，横跳或远离都会减少。
- 把整个下半平面铺满时，总势能收敛为 1。有限步之后场上仍剩无穷多颗棋子，因此不可能再腾出重量 1 的目标格。
